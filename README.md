# Projektátadási beszámoló

Webes eszköz a weboldal-projektek **szakmai beszámolójának** összeállításához: választható szövegblokkokból, projektenként, A4-es nyomtatással.

- Vue 3 + Vite + Tailwind, statikus oldal GitHub Pages-en
- Az adatok egy megosztott **Google Drive** mappában vannak (Google-bejelentkezés), szerver és adatbázis nélkül
- Beüzemelés: [SETUP.md](SETUP.md) · Specifikáció: [SPEC.md](SPEC.md)

```bash
npm install && npm run dev
```

> Ügyféladat, kitöltött beszámoló és sablonszöveg nem kerül a repóba, ezek a Drive mappában vannak.
